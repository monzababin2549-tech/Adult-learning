# เว็บไซต์ “จิตวิทยาในการจัดการเรียนรู้ของผู้ใหญ่”

เว็บไซต์ 5 หน้า ใช้ HTML + CSS + JavaScript ล้วน ไม่ต้องติดตั้งอะไรและไม่ต้องมี backend

## โครงสร้างไฟล์
```
adult-learning-site/
├─ index.html          หน้า 1 หน้าแรก (Adult vs Child)
├─ principles.html     หน้า 2 หลักการสำคัญ 6 ข้อ
├─ strategies.html     หน้า 3 เทคนิคการสอน / Facilitator
├─ models.html         หน้า 4 ARCS Model (tabs + accordion + diagram)
├─ application.html    หน้า 5 สรุป การประยุกต์ใช้ แหล่งเรียนรู้ และเกม quiz
├─ css/style.css       สไตล์ทั้งเว็บ (แบ่งส่วนตามหมายเลขในคอมเมนต์)
└─ js/
   ├─ main.js          navbar, progress หน้า x/5, ปุ่มย้อนกลับ/ถัดไป, footer, fade-in, tabs
   └─ quiz.js          เกม quiz 10 ข้อ
```

## วิธีรัน
1. แตกไฟล์ zip แล้วดับเบิลคลิก `index.html` เปิดด้วยเบราว์เซอร์ได้ทันที
2. (ทางเลือก) รันเซิร์ฟเวอร์ในเครื่อง: `python -m http.server 8000` แล้วเปิด http://localhost:8000
3. ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ Google Fonts (ถ้าไม่ต่อ จะใช้ฟอนต์ระบบแทน)

## วิธีแก้ไข
- เปลี่ยนชื่อหน้า/ลิงก์เมนู: แก้ตัวแปร `PAGES` ใน `js/main.js`
- เปลี่ยนสี: แก้ตัวแปรที่ `:root` ต้นไฟล์ `css/style.css`
- เพิ่ม/แก้ข้อสอบ: แก้อาร์เรย์ `QUESTIONS` ใน `js/quiz.js` (`answer` นับจาก 0)
- เปลี่ยนระดับเหรียญ: แก้ `LEVELS` ใน `js/quiz.js`

## ข้อเสนอแนะในการต่อยอด
- เพิ่มโหมดมืด และปุ่มปรับขนาดตัวอักษร
- เก็บคะแนนสูงสุดด้วย localStorage และสุ่มลำดับข้อ/ตัวเลือก
- เพิ่มเกมจับคู่ (เช่น จับคู่หลักการกับตัวอย่าง) หรือ flashcard ARCS
- เปลี่ยนภาพ SVG เป็นภาพถ่ายจริงของการอบรม
- ย้ายไป Next.js หรือ Eleventy หากต้องการหลายภาษาหรือเนื้อหาจำนวนมาก
